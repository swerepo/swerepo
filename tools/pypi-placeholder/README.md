# SWERepo (name reserved)

**This is a placeholder.** SWERepo isn't released yet; version 0.0.1 only reserves the name `swerepo` on PyPI. Installing it gives you a `swerepo` command that says so and exits.

SWERepo will set up a repository the way an AI-assisted team should work, and keep it that way: CI with a single required check, branch rules with code review, decision records and a progress log, instructions for AI agents, and locked rules through SeamSpec. `swerepo check` will report what a repository is missing; `swerepo update` will bring it up to the latest standard.

Follow the project: [github.com/swerepo/swerepo](https://github.com/swerepo/swerepo)
